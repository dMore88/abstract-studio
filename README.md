# Nature Gen Art 🌿✨

Una aplicación web de **arte generativo** enfocada en la exploración visual de patrones inspirados en la naturaleza, con controles interactivos para modular parámetros en tiempo real y opciones de exportación en SVG y código.

---

## 🎯 Propósito del Proyecto

El objetivo principal es ofrecer un espacio de **exploración visual interactiva** donde las matemáticas y los algoritmos que dan forma al mundo natural se conviertan en lienzos dinámicos.

### Pilares Clave

1. **Inspiración Natural**:
   Algoritmos y modelos basados en fenómenos biológicos, botánicos, geológicos y físicos (morfogénesis, crecimiento, dinámica de fluidos y ramificaciones).
2. **Exploración Paramétrica en Tiempo Real**:
   Controles interactivos e intuitivos (sliders, toggles, paletas de colores armónicas, semillas aleatorias) que permiten mutar y descubrir variantes estéticas de cada patrón.
3. **Exportación Versátil**:
   - **Vectorial (SVG)**: Ideal para ploteo de plumillas (pen plotters como Axidraw), corte láser, diseño gráfico o impresión en alta resolución.
   - **Código**: Exportación de snippets de código limpios (HTML/JS, Canvas o SVG) para que creadores y desarrolladores puedan integrar o estudiar el algoritmo.
   - Copiar al portapapeles o descargar directamente.

---

## 🔬 Ideas de Patrones y Algoritmos a Explorar

- **Filotaxis y Espirales Áureas**: Disposición de semillas de girasol, piñas y suculentas basada en la proporción áurea y espirales de Fermat.
- **Sistemas de Lindenmayer (L-Systems)**: Estructuras de ramificación fractal para modelar árboles, helechos (helecho de Barnsley) y redes vasculares.
- **Reacción-Difusión (Patrones de Turing)**: Simulación morfogénica similar a la pigmentación de pieles de animales (manchas de leopardo, rayas de pez cebra).
- **Campos de Flujo y Ruido Orgánico (Perlin / Simplex Flow Fields)**: Movimientos de viento, corrientes marinas, estelas y dunas de arena.
- **Diagramas de Voronoi y Teselaciones**: Estructuras celulares parecidas a panales de abejas, alas de libélula o caparazones.
- **Atractores Extraños y Ondas**: Patrones de interferencia de agua, resonancia y geometría armónica.

## 🛠️ Stack Tecnológico (Por Definir)

El stack se definirá según las necesidades del lienzo y el flujo de trabajo:
- **Renderizado**: SVG dinámico (DOM nativo / D3 / Paper.js) y/o Canvas / WebGL (p5.js, Three.js o código nativo ligero).
- **Frontend**: Framework moderno y reactivo (React / Vite, Svelte o Astro) con UI minimalista para los controles.
- **Exportación**: Generación de paths SVG limpios y serializers de código listos para producción.
